# Asset Pack v1 — Bosque Salvaje

Este directorio contiene piezas de runtime derivadas de los mockups canónicos aprobados. No se usa el mockup completo como fondo estático: las piezas se integran por capas para conservar cartas, estados y HUD dinámicos.

## cards/card_frame_overlay.webp
Marco ornamental extraído y limpiado desde la referencia `Cartas Básicas — Bosque Salvaje`. Tiene transparencia en las áreas dinámicas y se escala sobre cada carta renderizada.
